# 📝 TODO App using FastAPI

A simple and elegant TODO list web application built using **FastAPI**, **SQLite**, **SQLAlchemy**, and **Jinja2** templates. This app supports user registration, login, logout, task creation, and deletion.

---

## 🚀 Features

- 🔐 User Authentication (Register/Login/Logout)
- ✅ Add and delete TODO items
- 📦 SQLite database with SQLAlchemy ORM
- 🎨 Styled using custom HTML + CSS (No external frameworks)
- 🖥️ Jinja2 template rendering

---

## 🛠️ Tech Stack

- **Backend:** FastAPI, Starlette
- **Frontend:** HTML, CSS (Jinja2)
- **Database:** SQLite
- **ORM:** SQLAlchemy
- **Password Hashing:** Passlib
- **Session Management:** Starlette SessionMiddleware
